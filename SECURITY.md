# Security Policy

## Scope

This repository contains a **static portfolio showcase** for Novara Horizons Creations. It includes only HTML, CSS, and JavaScript files with no backend, no database connections, and no credentials.

## Reporting a Vulnerability

If you discover a security concern related to this repository or any Novara Horizons Creations product, please report it responsibly.

**Do not open a public GitHub issue for security reports.**

Contact us directly:

- **Email:** zvikkoh@gmail.com
- **WhatsApp:** +263 785 832 996

Please include:
- A description of the issue
- Steps to reproduce (if applicable)
- Potential impact

We will acknowledge your report within 48 hours and work to resolve confirmed issues promptly.

## What Is Not in This Repository

For transparency, the following are intentionally excluded from this public showcase:

- Database credentials and connection strings
- Production server configurations
- API keys and private tokens
- Client data or patient records
- Internal deployment scripts
