# GitHub Showcase Starter

This folder is a clean, public-safe showcase package for your development work.

## What is inside

- index.html: Portfolio landing page
- styles.css: Custom visual style
- app.js: Dynamic project rendering and filtering
- projects.js: Project data list you can edit quickly
- SECURITY.md: Security rules before publishing
- .gitignore: Protects common sensitive files

## How to customize

1. Update contact details in index.html
2. Replace placeholder GitHub links in projects.js
3. Add your other websites to projects.js
4. Change colors/text in styles.css and index.html as needed

## Upload to GitHub

1. Create a new public repository, for example novara-showcase
2. Copy only files from this showcase folder into that repository
3. Commit and push
4. Enable GitHub Pages from the main branch
5. Your portfolio will be live as a static site

## Good practice for your other websites

- Showcase workflow, screenshots, and outcomes
- Avoid uploading private client credentials or production configs
- Keep reusable architecture public, keep sensitive internals private
